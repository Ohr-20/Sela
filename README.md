# Sela / صلة

An elder-first Egyptian Arabic interactive presentation prototype. Open `index.html` directly in a browser. All CSS, interactions, illustrations and mock data are embedded in this file. Tailwind CDN and Tajawal font are optional online enhancements; the demo remains usable without them.

## Presenter flow

1. Quick Photo Speed-Dial: select a contact, confirm, observe a simulated call.
2. Community & Club: explore three Egyptian events and confirm participation.
3. Digital Safety: review a suspicious message and practice the safe response.
4. Human Help: connect to a simulated Egyptian support agent from any screen.

The five home tiles also include digital lessons, a simulated voice story and a service directory. Speaker buttons read Arabic text when an Arabic system voice is available. The reader toggle enables automatic narration. No audio is recorded, and no calls, bookings or messages are sent. All contact portraits are embedded vector illustrations; all people, events and verification badges are demo content.

## Accessibility

RTL layout, 22–24px body copy, 60px app controls, visible keyboard focus, dialog focus trapping, Escape dismissal, live status announcements, reduced-motion support and mobile layout.

## Hosting

Static Vercel project, no build or backend required. Import this repository into Vercel, or run `vercel --prod` in this directory after signing in.

The supplied brief refers to The Sela Model. Its source research was not supplied, so this prototype implements the requested features without claiming independent validation against that research.
